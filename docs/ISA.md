## 指令集概述

Simple CPU 采用精简指令集（RISC）架构，每条指令为 **32位** 定长格式。`opcode` 与 `funct` 共同确定操作；多数算术、访存和跳转指令使用立即数/寄存器两种寻址方式，比较指令使用独立的 `opcode=0x3/0x4`。

- **I-Type（立即数类型）**：使用16位立即数作为操作数
- **R-Type（寄存器类型）**：使用寄存器值作为操作数

```
指令格式:
31                 16  15  12  11   8  7    4  3    0
├─────────────────────┼───────┼───────┼───────┼───────┤
│   immediate/src_1   │ src_2 │ dest  │ opcode│ funct │
│       [15:0]        │ [3:0] │ [3:0] │ [3:0] │ [3:0] │
└─────────────────────┴───────┴───────┴───────┴───────┘
```

汇编语句规则：汇编器强制一行一条语句，不使用分号分隔。标签可以单独一行，也可以写成 `label: instruction`。

### 字段说明

| 字段 | 位宽 | 描述 |
|------|------|------|
| `imm` | 16位 [31:16] | 立即数 |
| `rs1` | 4位 [19:16] | 源寄存器1索引 |
| `rs2` | 4位 [15:12] | 源寄存器2索引 |
| `rd`  | 4位 [11:8] | 目标寄存器索引 |
| `opc` | 4位 [7:4] | 操作类型码 |
| `fun` | 4位 [3:0] | 功能码 |

### 寄存器约定

| 寄存器 | 说明 |
|------|------|
| `r0` | 零寄存器，读出恒为 0，写入无效 |
| `r1` | 软件可读写的中断控制寄存器；`[2:0]` 具有中断控制含义，不保存比较标志 |
| `r2` | 软件可读写的 32 位中断入口字节地址寄存器 |
| `r3` | 软件可读写的中断返回字节地址寄存器；接受中断时由硬件覆盖 |
| `r4-r14` | 软件可读写；其中部分寄存器由 ABI 约定为参数、临时值、FP、SP 和 LR |
| `r15` | 软件可读写的当前 PC 专用寄存器；不得作为普通通用寄存器使用 |

除 `r0` 外，`r1-r15` 均允许软件读写，以便操作系统保存和恢复完整寄存器上下文。可读写不改变专用寄存器的硬件功能，软件不得随意写入 `r1`、`r2`、`r3`、`r12-r15` 等 ABI 保留寄存器。

普通指令写入 `r15` 不会直接改变控制流；寄存器组空闲时，硬件会用当前指令字节地址刷新 `r15`。跳转必须使用 JAL、BZ 或 BNZ，按当前 PC 相对跳转时可以把 `r15` 作为基址。

### 中断寄存器与返回

`r1` 的位定义如下：

| 位 | 名称 | 访问属性与含义 |
|---|---|---|
| `r1[0]` | IRQ enable | 软件可读写；`0` 禁止中断，`1` 使能中断 |
| `r1[2:1]` | Trigger mode | 软件可读写；`2'b00` 为上升沿，`2'b01` 为下降沿，`2'b10` 为高电平，`2'b11` 为低电平 |
| `r1[31:3]` | Reserved | 软件可读写的保留位；硬件不在此保存比较状态 |

当前 Tiny C 的 `__irq_enable()` 只暴露 CPU 上升沿触发模式，写入 `r1=1`；`__irq_disable()` 写入 `r1=0`。

`r2` 保存 32 位中断入口字节地址。CPU 接受中断时执行且只执行以下架构动作：将已解析的下一条指令字节地址 `resolved_next_pc` 写入 `r3`，自动清除 `r1[0]`，然后跳转到 `R[r2]`。`r1[31:1]` 和其他寄存器均不由硬件自动保存或修改。

硬件不维护中断活动状态，不禁止嵌套，也不识别专用的“中断返回”指令。`jmp r3` 只是普通的寄存器间接跳转；何时返回、是否在返回前重新设置 `r1[0]`、是否保存上下文以及何时清除外设中断源，全部由软件决定。若软件未正确处理重复触发或嵌套，中断可再次进入或导致程序跑飞。

## 指令列表

### 1. 伪指令

汇编器在预编译阶段支持以下伪指令：

#### .equ - 常量宏定义

说明：编译阶段文本替换

**汇编示例：**
```
.equ uart_base 0x10000000       // uart_base -> 0x10000000
.equ uart_cfg (uart_base + 4)   // uart_cfg -> 0x10000004
.equ simulation                 // simulation defined
```

#### .prog - 输出文件名定义

说明：定义输出文件名，Verilog 输出时也作为 module 名

**汇编示例：**
```
.prog HelloWorld    // HelloWorld.v
```

#### .ifdef/.elsif/.else/.endif - 条件编译

说明：按宏是否已定义进行条件编译

**汇编示例：**
```
.ifdef UART
    mov r4, 0x1000
    mov r4, r4 << 16
.elsif ETH
    mov r4, 0x2000
    mov r4, r4 << 16
.else
    mov r4, 0x3000
    mov r4, r4 << 16
.endif
```

#### .macro/.endm - 代码片段宏定义

说明：定义带参数的代码片段，编译阶段文本替换

**汇编示例：**
```
.macro SetInt32(rd, hi, lo)
    mov rd, hi
    mov rd, rd << 16
    mov rd, rd + lo
.endm
```

#### .include - 文件引用

说明：将引用文件按声明顺序追加到主文件后一起汇编

**汇编示例：**
```
.include "macro.asm"
```

#### .rept/.endr - 重复展开

说明：将内部代码块重复声明多次

**汇编示例：**
```
.rept 10
    mov r8, r8 + 1
.endr
```

### 2. 数据传送指令

#### SETI - 设置立即数 (I-Type)

| 字段 | 值 |
|------|-----|
| 操作码 | `opcode=0001, funct=0000` |
| 操作 | `R[dest] = immediate` |
| 说明 | 将16位立即数符号扩展后存入目标寄存器 |

**汇编示例：**
```
mov r5, 100       // r5 = 100
```

#### SETR - 寄存器移动 (R-Type)

| 字段 | 值 |
|------|-----|
| 操作码 | `opcode=0010, funct=0000` |
| 操作 | `R[dest] = R[src_1]` |
| 说明 | 将源寄存器1的值复制到目标寄存器 |

**汇编示例：**
```
mov r5, r4         // r5 = r4
```

### 6. 内存访问指令

#### MWRI - 立即数偏移内存写 (I-Type)

| 字段 | 值 |
|------|-----|
| 操作码 | `opcode=0001, funct=1001` |
| 操作 | `Mem[R[src_2] + immediate] = R[dest]` |
| 说明 | 将 dest 寄存器的值写入 (src_2 + immediate) 地址的内存 |

**汇编示例：**
```
mov [r4 + 4], r5   // Mem[r4 + 4] = r5
```

#### MWRR - 寄存器偏移内存写 (R-Type)

| 字段 | 值 |
|------|-----|
| 操作码 | `opcode=0010, funct=1001` |
| 操作 | `Mem[R[src_2] + R[src_1]] = R[dest]` |
| 说明 | 将 dest 寄存器的值写入 (src_2 + src_1) 地址的内存 |

**汇编示例：**
```
mov [r4 + r6], r5   // Mem[r4 + r6] = r5
```

#### MRDI - 立即数偏移内存读 (I-Type)

| 字段 | 值 |
|------|-----|
| 操作码 | `opcode=0001, funct=1010` |
| 操作 | `R[dest] = Mem[R[src_2] + immediate]` |
| 说明 | 从 (src_2 + immediate) 地址读取数据到 dest 寄存器 |

**汇编示例：**
```
mov r6, [r7 + 8]   // r6 = Mem[r7 + 8]
```

#### MRDR - 寄存器偏移内存读 (R-Type)

| 字段 | 值 |
|------|-----|
| 操作码 | `opcode=0010, funct=1010` |
| 操作 | `R[dest] = Mem[R[src_2] + R[src_1]]` |
| 说明 | 从 (src_2 + src_1) 地址读取数据到 dest 寄存器 |

**汇编示例：**
```
mov r6, [r7 + r5]   // r6 = Mem[r7 + r5]
```

### 7. 跳转指令

#### JALI - 基址加立即数跳转并链接 (I-Type)

| 字段 | 值 |
|------|-----|
| 操作码 | `opcode=0001, funct=1101` |
| 操作 | `R[dest] = PC + 4; PC = R[src_2] + immediate` |
| 说明 | 将基址寄存器 `src_2` 与16位立即数相加作为跳转地址，并将返回地址存入目标寄存器；若 `dest=r0` 则不保存链接 |

**汇编示例：**
```
jmp 100, r6        // r6 = PC + 4, PC = r0 + 100
jmp r15 + 8        // 不保存链接，PC = 当前 PC + 8，跳过一条 32 位指令
jmp r8 - 4, r6     // r6 = PC + 4, PC = r8 + (-4)
```

#### JALR - 基址加寄存器跳转并链接 (R-Type)

| 字段 | 值 |
|------|-----|
| 操作码 | `opcode=0010, funct=1101` |
| 操作 | `R[dest] = PC + 4; PC = R[src_2] + R[src_1]` |
| 说明 | 将两个源寄存器相加作为跳转地址，并将返回地址存入目标寄存器；若 `dest=r0` 则不保存链接 |

**汇编示例：**
```
jmp r10, r6         // r6 = PC + 4, PC = r0 + r10
jmp r8 + r9, r6     // r6 = PC + 4, PC = r8 + r9
jmp r15 + r8        // 不保存链接，PC = 当前 PC + r8
```

### 8. 比较与分支指令

比较指令直接把布尔结果写入通用寄存器，不设置隐藏标志。汇编语法为：

```asm
cmp  rd, rs2 <op> rhs
cmpu rd, rs2 <op> rhs
```

`cmp` 对关系运算使用有符号比较，`cmpu` 使用无符号比较；两者均支持 `==` 和 `!=`。`rhs` 可以是寄存器或 16 位立即数。EQ/NE 和有符号关系条件将立即数符号扩展到 32 位；无符号关系条件将立即数零扩展到 32 位。`cmpu ==` 和 `cmpu !=` 与对应的 `cmp` 形式编码相同，因此按 EQ/NE 规则符号扩展。结果严格为 `0` 或 `1`。

| `funct` | 条件 | `cmp`/`cmpu` 含义 |
|---|---|---|
| `0x0` | `==` | 相等 |
| `0x1` | `!=` | 不相等 |
| `0x2` | `>=` | `cmp` 有符号大于等于 |
| `0x3` | `<` | `cmp` 有符号小于 |
| `0x4` | `>` | `cmp` 有符号大于 |
| `0x5` | `<=` | `cmp` 有符号小于等于 |
| `0x6` | `>=` | `cmpu` 无符号大于等于 |
| `0x7` | `<` | `cmpu` 无符号小于 |
| `0x8` | `>` | `cmpu` 无符号大于 |
| `0x9` | `<=` | `cmpu` 无符号小于等于 |

`cmpu` 的 `==`/`!=` 分别复用 `funct=0x0/0x1`。旧的隐藏比较标志以及 `brc/brcu` 指令已移除，汇编源码和机器码均不向后兼容。

#### CMPI - 立即数布尔比较

| 字段 | 值 |
|------|-----|
| 操作码 | `opcode=0011, funct=condition` |
| 操作 | `R[rd] = compare(R[rs2], sign_extend(imm16)) ? 1 : 0` |

```asm
cmp  r4, r5 > -1
cmpu r6, r7 < 0xffff
```

#### CMPR - 寄存器布尔比较

| 字段 | 值 |
|------|-----|
| 操作码 | `opcode=0100, funct=condition` |
| 操作 | `R[rd] = compare(R[rs2], R[rs1]) ? 1 : 0` |

```asm
cmp  r4, r5 == r6
cmpu r7, r8 >= r9
```

分支指令测试 `rd` 的当前值，不读取比较标志。立即数目标使用无符号 16 位加法，寄存器目标使用两个寄存器相加：

```asm
bz  rd, rs2 + label
bnz rd, rs2 + label
bz  rd, rs2 + rs1
bnz rd, rs2 + rs1
```

当不需要基址时必须显式使用 `r0`。标签会替换为绝对字节地址；汇编器只对 `r0 + label/u16` 的直接目标做 4 字节对齐检查，带运行时基址的最终地址由软件保证。

#### BZI/BNZI - 立即数目标零/非零分支

| 字段 | 值 |
|------|-----|
| 操作码 | `opcode=0001` |
| 功能码 | `BZ: funct=1011`；`BNZ: funct=1100` |
| 操作 | `condition ? PC = R[rs2] + zero_extend(imm16) : PC = PC + 4` |

`BZ` 的条件为 `R[rd] == 0`，`BNZ` 的条件为 `R[rd] != 0`。

```asm
bz  r4, r0 + loop_end
bnz r5, r2 + 0x100
```

#### BZR/BNZR - 寄存器目标零/非零分支

| 字段 | 值 |
|------|-----|
| 操作码 | `opcode=0010` |
| 功能码 | `BZ: funct=1011`；`BNZ: funct=1100` |
| 操作 | `condition ? PC = R[rs2] + R[rs1] : PC = PC + 4` |

```asm
bz  r4, r0 + r8
bnz r5, r6 + r7
```
