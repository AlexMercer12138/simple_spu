# 32 位迭代乘除法器设计

## 目标

在 `rtl/misc` 中新增可复用的 32 位迭代乘法器和除法器：

- `mul.v` 使用逐位移位加法，32 个迭代周期得到完整 64 位乘积。
- `div.v` 使用恢复除法的逐位移位减法，32 个迭代周期同时得到 32 位商和余数。
- 两个模块共用一套无符号运算数据通路，通过 `signed_mode` 选择是否在运算前求绝对值并在完成时修正符号。
- 设计以综合频率、Verilog-2005 兼容性和跨 FPGA 工具兼容性为优先，不使用 `*`、`/` 或 `%` 运算符实现核心运算。

## 模块接口

### `mul`

```verilog
module mul (
    input  wire        clk,
    input  wire        rst_n,
    input  wire        start,
    input  wire        signed_mode,
    input  wire [31:0] operand_a,
    input  wire [31:0] operand_b,
    output reg         done,
    output reg  [63:0] result
);
```

### `div`

```verilog
module div (
    input  wire        clk,
    input  wire        rst_n,
    input  wire        start,
    input  wire        signed_mode,
    input  wire [31:0] dividend,
    input  wire [31:0] divisor,
    output reg         done,
    output reg  [31:0] quotient,
    output reg  [31:0] remainder
);
```

`rst_n` 为低有效同步复位，与 `rtl/misc` 现有时序模块保持一致。复位时清零 `done` 和全部结果输出。模块内部维护运行状态，但不导出 `busy`。`start` 仅在内部空闲时采样，调用方必须提供单周期脉冲；运行期间出现的 `start` 被忽略。`done` 在结果有效时拉高一个周期，结果保持不变直至下一次运算完成或模块复位。

若在时钟沿 N 采样到有效的普通运算 `start`，模块在随后 32 个时钟沿完成 32 次迭代，并在时钟沿 N+32 更新结果及拉高 `done`。除零在采样 `start` 的同一时钟沿更新约定结果并拉高 `done`。

## 乘法数据通路

启动时，根据 `signed_mode` 和两个操作数的最高位分别取得 32 位无符号绝对值，并锁存最终结果是否需要取负。`32'h8000_0000` 的绝对值仍以无符号 `32'h8000_0000` 表示，因此不需要额外位宽。

内部使用 64 位累加器、64 位左移被乘数和 32 位右移乘数。每个运行周期检查乘数最低位，必要时只执行一次 64 位加法，然后完成移位。第 32 次迭代使用本周期加法后的值产生结果，并按锁存的符号对完整 64 位乘积取补码。

无符号模式返回完整的 64 位无符号乘法结果。有符号模式返回完整的 64 位二进制补码乘法结果。两种模式的低 32 位相同。

## 除法数据通路

启动时，根据 `signed_mode` 取得被除数和除数的无符号绝对值，并分别锁存商是否需要取负以及余数是否需要取负。商的符号是两个输入符号的异或，余数符号始终与被除数一致。

内部使用 33 位部分余数、32 位待移位被除数、32 位商和 32 位除数。每个运行周期把下一位被除数移入部分余数，执行一次无符号比较，必要时执行一次 33 位减法，并把所得商位移入商寄存器。第 32 次迭代使用本周期比较和减法后的商及余数产生输出，再按锁存的符号分别取补码。

有符号除法采用向零截断语义。例如 `-7 / 3 = -2`，余数为 `-1`。`32'h8000_0000 / 32'hffff_ffff` 的商按 32 位自然回绕为 `32'h8000_0000`，余数为零。

## 除零行为

除数为零时不启动 32 周期迭代，直接返回：

```text
quotient  = 32'hffff_ffff
remainder = dividend
```

模块正常产生单周期 `done`，不提供异常或除零状态输出。该规则对有符号和无符号模式相同。

## ISA 映射建议

`signed_mode` 由当前指令译码结果直接驱动，不通过软件可见状态寄存器配置。32 位寄存器只保存乘积低 32 位时，有符号和无符号乘法结果相同，因此基础 ISA 只需要一条 `mul`。除法和取余应分别提供：

```text
mul   rd, rs2, rs1
div   rd, rs2, rs1
divu  rd, rs2, rs1
rem   rd, rs2, rs1
remu  rd, rs2, rs1
```

若以后需要访问乘积高 32 位，再增加有符号 `mulh` 和无符号 `mulhu`。本次任务只实现独立算术模块及其测试，不修改 CPU 译码、汇编器或编译器。

## 验证

为两个模块分别编写自检 testbench，至少覆盖：

- 零、一、最大无符号数和普通随机风格数值。
- 正数、负数、异号操作数和两个负数。
- `32'h8000_0000`、`32'hffff_ffff` 等补码边界。
- 乘法完整 64 位结果。
- 除法的商和余数，以及 `dividend = quotient * divisor + remainder` 关系。
- 除零约定。
- `start` 在运行期间被忽略。
- `done` 仅保持一个周期。
- 每次正常运算在 32 个迭代周期后完成。

使用 Icarus Verilog 以 Verilog-2005 模式编译并运行测试。测试中的期望值可以使用行为级算术运算符，待测 RTL 的核心数据通路不得使用乘除运算符。
