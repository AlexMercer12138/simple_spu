# APB I2C Peripheral Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and verify a 32-bit APB I2C peripheral with mutually exclusive master/slave modes, parameterized byte FIFOs, configurable 7-bit slave address, direct write, direct read, and write-RESTART-read master commands.

**Architecture:** `apb_i2c.v` owns APB registers, FIFO storage, command checks, mode control, and interrupts. Refactored `i2c_master_lite.v` and `i2c_slave.v` are protocol engines connected to the wrapper by byte-wide valid/ready interfaces. Tests progress from isolated protocol engines to two complete APB instances sharing resolved open-drain lines.

**Tech Stack:** Verilog-2005, APB3-style 32-bit register interface, vks lint/compile/simulate workflow, available independent simulator fallback, Git commits limited to I2C/test/document files.

---

## File Structure

- Modify `rtl/i2c/i2c_master_lite.v`: replace the fixed-vector core with a streaming master engine.
- Modify `rtl/i2c/i2c_slave.v`: replace the register-addressed slave with a runtime-addressed streaming slave.
- Create `rtl/i2c/apb_i2c.v`: APB registers, FIFOs, mode mux, command validation, and IRQ logic.
- Create `rtl/sim/tb_i2c_master_lite.v`: isolated master protocol tests.
- Create `rtl/sim/tb_i2c_slave.v`: isolated slave protocol and stretch tests.
- Create `rtl/sim/tb_apb_i2c.v`: two-controller end-to-end APB tests.
- Create `rtl/i2c/apb_i2c_manual.md`: final software register and programming guide.

The existing `rtl/misc/sync_fifo.v` is not changed or used.

## Required Core Interfaces

The master rewrite uses this exact module boundary:

```verilog
module i2c_master_lite (
    input  wire        clk,
    input  wire        rst_n,
    input  wire        enable,
    input  wire        cmd_start,
    input  wire [1:0]  cmd_op,
    input  wire [6:0]  cmd_addr,
    input  wire [7:0]  cmd_tx_len,
    input  wire [7:0]  cmd_rx_len,
    input  wire [15:0] scl_prescale,
    input  wire [31:0] timeout_cycles,
    input  wire [7:0]  tx_data,
    input  wire        tx_valid,
    output reg         tx_ready,
    output reg  [7:0]  rx_data,
    output reg         rx_valid,
    input  wire        rx_ready,
    output reg         busy,
    output reg         done,
    output reg         addr_nack,
    output reg         data_nack,
    output reg         arbitration_lost,
    output reg         timeout,
    output reg         bus_error,
    output reg  [7:0]  tx_count,
    output reg  [7:0]  rx_count,
    input  wire        abort,
    output wire        scl_o,
    output reg         scl_t,
    input  wire        scl_i,
    output wire        sda_o,
    output reg         sda_t,
    input  wire        sda_i
);
```

`cmd_op` values are `2'b00` write, `2'b01` read, and `2'b10` write then read. Event outputs are one-clock pulses. `tx_ready` pulses when a FIFO byte is captured. `rx_valid` remains asserted with stable `rx_data` until `rx_ready` completes the handshake.

The slave rewrite uses this exact module boundary:

```verilog
module i2c_slave (
    input  wire        clk,
    input  wire        rst_n,
    input  wire        enable,
    input  wire [6:0]  device_addr,
    input  wire [31:0] timeout_cycles,
    output reg  [7:0]  rx_data,
    output reg         rx_valid,
    input  wire        rx_ready,
    input  wire [7:0]  tx_data,
    input  wire        tx_valid,
    output reg         tx_ready,
    output reg         selected,
    output reg         read_mode,
    output reg         stretch_active,
    output reg         bus_busy,
    output reg         rx_done,
    output reg         read_done,
    output reg         rx_overflow,
    output reg         tx_underflow,
    output reg         stretch_timeout,
    output reg         bus_error,
    output reg  [7:0]  rx_count,
    output reg  [7:0]  tx_count,
    output wire        scl_o,
    output reg         scl_t,
    input  wire        scl_i,
    output wire        sda_o,
    output reg         sda_t,
    input  wire        sda_i
);
```
